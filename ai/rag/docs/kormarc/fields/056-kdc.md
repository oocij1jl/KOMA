## Purpose

056 필드는 한국십진분류기호(KDC)를 기술하는 필드이다. 이 서비스에서는 정보나루 `class_no`에서 온 `evidence.kdc_from_api`를 우선 근거로 사용한다.

KDC는 검수 위험이 높은 분류 필드이므로 API 값이 있어도 `review_required=true`로 둔다. API 값이 없으면 키워드와 책소개만으로 확정 분류를 만들지 말고, 후보 제안 여부를 매우 보수적으로 판단한다.

## Official KORMARC Summary

- 반복 가능 필드이다.
- 해당 시 필수 성격의 필드이다.
- 제1지시기호와 제2지시기호는 미정의이므로 공백으로 표시한다.
- 주요 식별기호는 `a`이며 KDC 분류기호를 기술한다.
- `2` 식별기호에는 적용된 KDC 분류표의 판을 기술한다.
- 복수 주제나 별법 규정에 따라 분류기호가 여러 개 부여되면 `a`를 반복할 수 있다.

## Service Generation Rule

1. `evidence.kdc_from_api`가 빈 문자열이 아니면 그 값을 056 `a` 후보로 사용한다.
2. KDC 판차가 API에서 제공되지 않으면 `2`는 빈값으로 두고 `review_required=true`를 유지한다.
3. API KDC가 없고 `keywords`, `description`만 있는 경우에는 확정값을 만들지 않는다.
4. 키워드/책소개 기반 KDC 후보를 제안해야 하는 경우 `source="ai_inference"`, `confidence="low"`, `review_required=true`를 부여한다.
5. 분류기호와 판차는 사서 검수 대상이다.
6. 도서기호, 청구기호, 기관 부호는 근거 없이 만들지 않는다.

## Skip Rule

| Condition | Reason |
|---|---|
| `kdc_from_api`가 빈 문자열이고 `evidence.available.keywords=false`, `evidence.available.description=false`임 | `근거 부족: 056 생성에 필요한 evidence 미수집` |
| 키워드/책소개만으로 분류 후보를 좁힐 수 없음 | `KDC 후보 불명확: 임의 생성 금지` |
| 청구기호 또는 도서기호만 추정 가능한 경우 | `청구기호/도서기호 임의 생성 금지` |

## Risk and Validation

- 056은 항상 `review_required=true`로 둔다.
- API 값이면 `source="api"`, 추론 후보이면 `source="ai_inference"`로 둔다.
- `source="ai_inference"`이면 `evidence` 객체가 필수이다.
- `indicator1`, `indicator2`는 공백이어야 한다.
- `a`에는 KDC 분류기호만 넣고 청구기호 전체를 넣지 않는다.
- `2` 판차가 비어 있으면 검수 배지를 강조한다.
