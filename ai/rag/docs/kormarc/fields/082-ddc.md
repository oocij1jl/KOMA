## Purpose

082는 듀이십진분류기호를 기술하는 재량 반복 필드다. 이 서비스에서 082는 국중도 DDC에서 온 biblio.ddc를 코드가 전사할 때만 만든다. LLM은 082를 생성하지 않는다.

## Indicators

제1지시기호는 판의 유형으로 0 완전판, 1 간략판, 7 식별기호 2에 다른 판을 직접 입력이다. 제2지시기호는 분류기호의 출처로 공백 해당정보 없음, 0 미국의회도서관, 1 국립중앙도서관, 4 기타 기관이다. 이 서비스는 판 유형과 부여 출처를 확정할 근거가 없으므로 둘 다 공백으로 두고 검수에 맡긴다.

## Subfields

허용 식별기호는 a 듀이십진분류기호, b 도서기호, m 표준/임의규정 표시, q 부여기관, 2 판 표시, 6, 8이다.

## Service Generation Rule

biblio.ddc가 있으면 a에 전사한다. biblio.ddc_edition이 있으면 2에 기술하고 없으면 만들지 않는다. 항상 review_required=true다.

## Skip Rule

biblio.ddc가 비어 있으면 082를 만들지 않고 'DDC 근거 없음: API 분류기호 미수집'을 남긴다. KDC 값을 DDC로 변환하지 않는다. 주제만 보고 DDC를 추론하지 않는다. 판 표시를 지어내지 않는다.
